# T-Cross Highline 2022 — Páginas de venda

Landing pages para a venda da VW T-Cross Highline TSI 2021/2022 branca.

## Links das páginas (GitHub Pages)

- **Versão elegante (principal):** https://rivanbello.github.io/tcross/
- **Versão vendedora:** https://rivanbello.github.io/tcross/vendedor.html

## Como subir as fotos

As páginas já esperam as fotos na pasta `fotos/`, com estes nomes exatos:

| Arquivo               | Foto                |
|-----------------------|---------------------|
| `fotos/frente.jpg`    | Frente do carro     |
| `fotos/lateral.jpg`   | Lateral             |
| `fotos/traseira.jpg`  | Traseira            |
| `fotos/interior.jpg`  | Interior / painel   |
| `fotos/detalhes.jpg`  | Detalhes            |

Passo a passo pelo site do GitHub:

1. Abra a pasta [`fotos/`](fotos/) aqui no repositório.
2. Clique em **Add file → Upload files**.
3. Arraste as 5 fotos (já renomeadas com os nomes acima) e clique em **Commit changes**.
4. Aguarde ~1 minuto e recarregue a página — as fotos aparecem sozinhas,
   sem precisar mexer em código.

Enquanto uma foto não existir, a página mostra um placeholder no lugar.
