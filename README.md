# T-Cross Highline 2022 — Páginas de venda

Landing pages para a venda da VW T-Cross Highline TSI 2021/2022 branca.

## Links das páginas (GitHub Pages)

- **Versão elegante (principal):** https://rivanbello.github.io/tcross/
- **Versão vendedora:** https://rivanbello.github.io/tcross/vendedor.html

## Fotos

A galeria usa os arquivos da pasta [`fotos/`](fotos/) — 8 fotos: frente
(2 ângulos + detalhe), traseira (+ detalhe), painel, posto do motorista e
bancos traseiros. Para trocar alguma, basta subir um arquivo novo com o
mesmo nome pela interface do GitHub (**Add file → Upload files**).
