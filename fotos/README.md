# Pasta de fotos

Suba aqui as fotos do carro com estes nomes exatos (formato .jpg):

- `frente.jpg`
- `lateral.jpg`
- `traseira.jpg`
- `interior.jpg`
- `detalhes.jpg`

Pelo site do GitHub: **Add file → Upload files**, arraste as fotos e
clique em **Commit changes**. Em ~1 minuto elas aparecem nas páginas.
